LaloCourse

Online learning platform

Six creative examples built around one core angle.

Concept work for an illustrative brand. Built to demonstrate how one insight becomes a set of ads to test.

The brand & problem
LaloCourse is an illustrative online learning platform. The challenge: make a course feel relevant to someone deciding whether it is worth their time.
The insight
A promotion or career switch can be a stronger reason to learn than access to a large course library.
The creative angle

From first lesson to career move.

The creative system

One central message, explored through career goals, an evening study routine, a course path, an illustrative testimonial layout and a message comparison.

Six creative examples, including a motion opening frame and a message comparison. Shown as still images.

Why this could work

A career goal connects the course to something the customer already wants. Showing a path toward that goal could help them see why the learning is worth starting. A performance team can test career-switching and progression hooks while keeping the link between learning and a career goal consistent.
